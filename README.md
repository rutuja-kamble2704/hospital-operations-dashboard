# 🏥 Hospital Operations & Patient Flow Analysis Dashboard

## 📌 Overview

This project presents a **Power BI dashboard** designed to analyze hospital operations using patient, encounter, condition, and payer data. The goal is to uncover actionable insights that improve **operational efficiency, patient flow, and resource utilization**.

---

## 🎯 Objectives

* Analyze **patient inflow trends** across different time slots
* Identify **peak hours and operational bottlenecks**
* Evaluate **provider and encounter performance**
* Understand **payer distribution and its impact on revenue flow**
* Improve **hospital resource planning and scheduling**

---

## 📊 Dataset Description

The dataset includes structured healthcare data across multiple tables:

* **Patients** → Unique patient records
* **Encounters** → Visit details with start & stop timestamps
* **Conditions** → Diagnosed medical conditions
* **Providers** → Healthcare professionals involved


---

## 🔍 Key Insights

* ⏰ **Peak Time Analysis:** Patient volume is highest during specific time ranges (e.g., 1–4 PM), indicating need for optimized staffing
* 🏥 **Encounter Bottlenecks:** Longer encounter durations highlight inefficiencies in patient handling
* 👩‍⚕️ **Provider Utilization:** Uneven workload distribution across providers suggests scope for better allocation
* 💳 **Payer Dependency:** High reliance on certain payers may affect financial stability
* 🔄 **Patient Flow Issues:** Delays between encounter start and stop times indicate process gaps
* 📈 **Operational Opportunity:** Data-driven scheduling can significantly reduce wait times and improve service quality
